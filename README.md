# 贪吃蛇 🐍

一个极简的网页版贪吃蛇游戏，纯原生 HTML + CSS + JavaScript，无任何依赖、无需构建，双击 `index.html` 就能玩。

## 玩法

| 操作 | 键位 |
| --- | --- |
| 移动 | 方向键 ↑ ↓ ← → 或 `W` `A` `S` `D` |
| 暂停 / 继续 | 空格键 |
| 手机 | 在棋盘上滑动屏幕 |

- 吃到红色方块 +1 分，蛇身变长
- 分数越高，速度越快（最低 70ms 一步）
- 撞墙或撞到自己，游戏结束
- 最高分保存在浏览器 `localStorage` 里

## 运行

```bash
# 方式一：直接打开
open index.html        # macOS
start index.html       # Windows

# 方式二：起个本地服务（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
